# 合成资源掉落配置

配置位置：`data/rules.json` → `merge_resource_drops`。

| 棋盘 | 默认资源与概率 |
|---|---|
| `main` 主棋盘 | 贝币 4%、沙漏 3%（部落3级起）、琥珀 0.1% |
| `event` 活动棋盘 | 琥珀 20%、体力 25% |

每条配置包含 `item`（资源物品ID）、`chance`（0到1的概率），可选 `min_level`（部落等级，默认1）、`items_only`（只限普通物品合成，默认false）。资源可选 `shell_1`、`sand_1`、`amber_1`、`fire_1`；运行时统一降为一级。修改数组可添加、移除资源或调整顺序及概率；空数组关闭掉落。

每次成功合成最多掉落一件。各条配置依次占据概率区间，未命中则不掉落；总概率应不超过1。移动、交换、失败合成不触发。主棋盘引导期间及无空位不掉落，掉落放在最近空格；活动棋盘掉落进入主棋盘暂存区，避免将主棋盘资源混入活动专属物品链。

客户端与服务端读取同一份配置。主棋盘沿用合成事件哈希同步随机结果，活动在线模式由服务端判定并记入物品额度。旧 `merge_coin` / `merge_sand` 字段仅保留兼容辅助查询，正式掉落以新配置为准。
