# 主角说话方式

依据卡册已有63条文案，重点参照采摘、洞穴生活、食物与烹饪、酋长与族人、发明与发现。卡册是当前游戏人物口吻的首要依据。

阿焰把玩家当一起找吃的兄弟。他观察具体的东西，饿了先找果子，干活会算自己分到多少，也会用很认真的语气得出奇怪结论。他有小聪明，会偷尝、忘记藏东西的位置、留意酋长怎么分东西；也会吃瘪、怕吃亏。说完笑点就停，不解释为什么好笑。

台词用短句和平静的语气。发现新机制时适合说“兄弟，我发现……”，连续操作中自然接话，避免每句都重复句式。每段明确交代该点什么、拖什么、如何获得奖励，人物口吻不能模糊操作或编造机制。

减少“我相信你能做到”“大家一定会喜欢”“为了部落越来越好”一类热情鼓励、欢迎词和集体建设口号。没有情境时不硬塞流行词、现代职场术语或酋长笑话。顾客、酋长和其他族人的发言由各自角色决定。

当前主角头像的发言入口是强引导`Guide`和后续一次性提示`Tips`。两者共用`assets/characters/hero_voice.json`；`scripts/ui/HeroVoice.gd`只负责展示查表。教程步骤、操作目标、奖励和存档标识继续由原玩法配置负责。

升级结算是酋长给合成劳动发工钱：主角干活、酋长定价，奖励预览写“下一级工钱”，领取界面写“酋长发工资”。台词可以平静地算账和抱怨使唤，实际声望仍来自带星心愿，奖励数额及一次性领取规则沿用原配置。

界面将资源名写成「不那那」，保留金棕色，字号与正文一致。引导优先一句说清当前操作，发现梗与工钱笑话只在合适的地方出现。

普通产品合成以正常配置的5%概率直接掉落2级不那那（整根），新手不保底、不补发，也不占掉最后一个生产空位。取消香蕉收取引导，任何等级都不提示或强制收取；玩家自行决定合成、解锁藤蔓或收取。旧版停在该引导的存档自动接回后续流程，已有香蕉保留。
