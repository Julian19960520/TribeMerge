# 新手教程逐图对照

依据仓库中的《竞品新手教程逐图解说.xlsx》逐图解说页，共131图。保持部落题材；袋子对应采集篮，食材主线对应水果，副线对应种子，金币对应不那那，钻石对应琥珀，餐盖对应心愿补给篮。

教程流程、订单投放和截图映射统一配置在 `data/onboarding.json`。剧情和导航用 `onboarding_next` 记录，合成、生产、交单、建设、取菜由实际游戏状态推进；强引导只放行目标，自由阶段移除蒙层。

用户明确指定的例外：部落建造不参考竞品流程，恢复为普通部件建造面板中点击建造→自动播放原来的锤击、部件落地和星星动画→显示建成奖励。移除建材箱、二次点击安装、跳过按钮、新手专用阶段面板以及第二次建造后的强制下一阶段预览/玩法说明。原表建造行保留为视频记录，不再作为上述交互的实现要求。既有建造费用、奖励和已建部件不重置；旧存档停在预览/说明步骤时自动接回原有后续引导。

副产物难度复核（第67–81图）：原版也依次要求副产物3、4、5级，并非降低了最后一单等级。完成依赖棋盘预放的副产物和逐步清地；第79图还领取了15体力。原视频没有展示产出百分比，不能确认原版也采用5%。重新查看第69、74图可确认两处仍未对齐的预放供给：(3,2)为锁定的3级副产物，(4,6)为锁定的1级副产物；当前配置对应位置是`cloth_5`与空格。这两份供给等价于5份初级副产物，若完全用5%随机产出补足，期望额外生产100次。此项是已确认的棋盘供给差异；本次建造流程恢复没有改动副产物掉率、订单或预放供给。

当前节奏调整：订单优先接在藤蔓合成之后，教学首张樱桃订单保留原操作；后续普通教学单的需求若与已露出的藤蔓同级，则沿可解锁的合成链提升目标，已提升目标不回退。种子阶段先用一张主产物订单过渡，松果需求改为合成藤蔓后的核桃；随机普通单也避开可见藤蔓材料，并在原难度范围内偏好解锁后的产物。

4级制作从4单减为2单：野苹果拼盘只需6级野苹果，烘烤坚果只需4级松果；两单各给2声望，加上一张普通单完成5声望升级，经验表不变。新手坚果需求从4次减为2次：2级仅保留一单，基准4级，遇同级藤蔓时接合成产物；另一张2级坚果单和5级末单改为主线果子。基础一级坚果需求总量从64降为16（未计藤蔓预放物）。配置版本4会替换尚未备齐的旧重复需求，保留订单身份及经验；已备齐、已开工或已做好的订单按原内容完成。

明确数值：初始100体力、30琥珀；三张练习单分别奖励4、42、12，不带声望；前五级升级需求2、5、3、5、5。前三次建设花费46、67、162，奖励分别为体力10、体力10及生产器部件、琥珀10。首次补100体力免费，后续10琥珀。2级送琥珀10及体力10，3级送沙漏120及部件，4级送沙漏180及火种罐/部件，5级送沙漏180。

表格的截图余额和个别注释存在内部矛盾：汇总称“四张练习单”，逐图只列三张；4+42=46，首次建设发生在第三张交付前；第27图领取14金币，后续截图余额却未计入；第116–122图不足以复原一条唯一的结算顺序。实现优先遵循逐图操作、明示奖励和实际到账，不清零或扣除玩家额外取得的资源。自由阶段的耗时、随机掉落、剩余体力和可选购买取决于玩家操作，不按视频秒数强制播放。

清地奖励：2级首次免费补充已经用过、再次耗尽且清出14格时，出现可领取的15体力奖励；领取通过独立命令结算，保存后不会重复发放。

制作与等待：首次制作只用一颗野莓、10秒；3级两道菜可同时制作，10/20秒；4级引入180/240秒的等待。订单卡将原料、手绘“=>”和产物排成一行，多原料适度重叠。配方教学只圈产物图标，亮区完整放行点击；制作中底部奖励列表换成倒计时进度条，沙漏费用放在图标右下角。计时按每6秒一份沙漏计算跳过费用，不强制教授跳过。做完先在设备上显示完成，点击设备取菜后才能交单。

火种罐统一为4级新人奖励生产器：从领奖开始有效7天，每12小时回满8次，不叠加，每次免费生成2～4级体力物品；首次产出保留罐子，不再有一次性三个物品合成100体力的分支。暂存区也计有效期，到期只移除罐子；已有体力物品保留。12级不再发放，旧版已消费一次性礼盒且仍在教程中的玩家补回一次。体力见底或4级两张制作完成时提示，过期自动跳过相关步骤。

宝箱先选中、再次点击出物，首次成功产出后使用开盖图片并禁止合并；储物和移动保留状态，末件物品先飞向其他空格再移除箱子外观。图鉴页签有可领取奖励时显示红点，切换后定位第一个可领取物品。热卖固定六格，第六格为随机产线的一级生产器部件，120琥珀、每轮限购一次，刷新和保存恢复遵循同一规则。

保存：教程步骤、已发订单、已交订单、产出、新人生产器有效期和次数写进重放元数据；旧玩家保留已有棋盘、余额和进度，不强制从新开场重玩。
