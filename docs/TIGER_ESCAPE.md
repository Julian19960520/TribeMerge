# 逃离剑齿虎

主棋盘任务栏的独立活动，默认6级解锁；GM活动提前解锁开关同样有效。玩家主动点击“开始逃生”后计时，每局10个推进目标。每完成一张主棋盘订单获得1积分；合成、移动、交换、领取资源、活动棋盘操作均不加分。满当前目标自动向前跳，溢出的积分继续计入下一跳。

剑齿虎默认每3小时（10800秒）摧毁一处节点，从出发点开始，按真实经过的时间追击。摧毁当前站位即出局；截止时刻的合成不能挽救已被追上的玩家。离线、关闭面板均不暂停追击，重新打开或服务端收到操作时会补算。完成全部10阶段立即胜利，此后不再被淘汰。

每处节点都有可预览的补给礼包，抵达后点击可领取一次；已抵达节点即使后来被摧毁，奖励仍然有效。出局或胜利后点“再逃一次”，会结清所有已到达但未领取的奖励，再开启新一局，不回收旧奖励、不重复发放已领取奖励。新一局需玩家主动开始，避免离开面板时自动开始倒计时。

## 配置

`data/tiger_escape.json`：`unlock_level`、`attack_interval_sec`、`points_per_order`、`stages`。每阶段包含 `points` 和 `rewards`（现有统一领奖格式）。每局开始时复制规则到本局状态，调整配置不会改变正在进行的局或重复更改已赚取的奖励。

## 存档与服务端

状态 `tiger_escape` 同时写入本地存档和云状态，服务端不接纳客户端上传的成绩或领取状态。在线模式只在服务端接受主棋盘 `order` 事件后加分，复用事件去重逻辑；开局、领取、重开走 `/v1/tiger/action`，复用账号锁和幂等键。离线模式使用相同规则，联网时以服务端为准。

界面提供路径拖动、当前进度、扑击倒计时、跳跃过渡、被摧毁节点、礼包预览和领奖、规则说明。未开始/追击中/出局/胜利四态均可显示。新增15名有名字与头像的模拟同行者，各自按预生成的时间曲线跳向下一节点，赶不上对应节点的截止时间会淘汰；断线补算按事件先后结算，避免离线时让已经被追上的假人复活。界面展示同行者的位置与存活人数。

倒计时结束后在面板内立即播放剑齿虎扑食、角色缩小被吃掉及落脚点碎裂动画；面板关闭时保留未播放攻击，下次打开补播。动画后才显示淘汰结果。播放确认单独保存在 `tiger_escape_seen`，中途关闭可再次补播，已完整播放的同一次攻击不重复。活动入口显示阶段进度和未领取奖励提示。

验证：`tools/check_tiger_escape.gd`（独立存档、`--cloud-off`），`server/tests/test_tiger_escape.py`。

旧版仍在进行的分钟级合成局自动迁移为小时级订单局，保留已到达节点和已领取礼包，旧合成的零散积分不换算成订单积分。
