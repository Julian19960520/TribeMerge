# 界面文案总表

**唯一编辑入口：[texts.json](texts.json)。** 游戏界面、物品与建筑名称、提示、对白、卡册、服务端提示和配置工具文案都在这个文件中。顶部 `stats` 是去重统计；等级、数量、时间的不同数值不重复计数。

| 字段 | 含义 |
| --- | --- |
| 条目编号 | 稳定引用，代码与玩法配置使用它，勿修改 |
| `zh_CN` | 当前中文，在此修改文案 |
| `en_US` | 英文翻译预留，留空自动回退中文 |
| `source` | 兼容旧逻辑和存档的原始模板，勿修改 |
| `scope` | `runtime` 玩家界面；`developer` 配置工具；`legacy_story` 旧剧情 |
| `category` | 界面、名称、对白、卡册、提示等用途分类 |
| `placeholders` | 按顺序列出动态参数类型；`s` 文字、`d` 整数、`f` 小数 |
| `refs` | 引用文件与代码行号，或 JSON 路径 |

中文和译文必须保留原模板的 `%s`、`%d` 等占位符的数量、类型与顺序，以及富文本标签。`%%` 表示显示一个百分号。仅改 `zh_CN` / 译文不改玩法指纹、物品 ID、订单、概率或玩家进度。图片内烘焙的字、引擎自带界面、历史存档迁移快照和离线素材工具不属于此统计。

配置中的 `§条目编号§` 会在加载时还原成稳定原文，再进入玩法校验与冻结；界面显示时读取目标语言。配置编辑器保存已知文案时仍写编号。已有的动态字符串通过显示入口兼容，新界面可以直接使用 `TextCatalog.text("条目编号", [参数])`。`TextCatalog.source()` 用于需要稳定值的旧逻辑。

新增文案后执行 `python tools/text_catalog.py --sync`，自动提取、去重、绑定显示入口并更新位置统计。发布检查执行 `python tools/text_catalog.py --check`，遗漏条目、无效引用和翻译占位符错误都会阻止发布。发布版本同时提供 `/texts.json`，与工程内的总表完全一致。

增加语言时，在 `locales` 中加入语言代码，并在各条目中填同名字段。启动界面前调用 `TextCatalog.set_locale("语言代码")`；已构建的界面需重新创建或刷新，当前没有额外添加语言选择界面。字体覆盖、译文长度和不同语言排版需随具体译文验收。
